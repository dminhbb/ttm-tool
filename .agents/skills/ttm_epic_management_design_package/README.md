# TTM Epic Management Design Package

Gói này chứa hướng dẫn thiết kế và CSS cho màn hình Quản lý Epic dành cho PM-SM/User.

## Files

```text
docs/epic-management-design-guide.md
css/tokens.css
css/layout.css
css/components.css
css/epic-table.css
css/responsive.css
css/ttm-epic-management.css
demo/epic-management-demo.html
demo/source-pm-report-unified.html
```

## Cách xem demo

Mở file:

```text
demo/epic-management-demo.html
```

## Cách dùng nhanh trong HTML

```html
<link rel="stylesheet" href="css/ttm-epic-management.css" />
```

## Cách dùng trong Next.js

Copy file `css/ttm-epic-management.css` vào `src/app/globals.css` hoặc import các file CSS thành phần theo kiến trúc frontend của project.
