# AI Decision Rules

## Choosing containers

Use Card:
- when content has its own clear meaning
- when content can move/reorder as a block

Use Section:
- when grouping content within a page

Avoid nested cards more than 2 levels deep.

## Choosing charts

Time over time -> Line chart

Categories -> Bar chart

Composition -> Stacked bar

Single target -> Gauge or progress

Exact values -> Table

Ranking -> Leaderboard

## Choosing navigation

5 or fewer peer sections -> Tabs may work

Many application modules -> Sidebar

Temporary contextual actions -> Menu / popover

## Choosing overlays

Short decision -> Modal

Object details/edit -> Drawer

Complex process -> Page

## Choosing status

Low emphasis -> status dot + text

Medium emphasis -> subtle badge

High emphasis -> alert / banner

## Choosing actions

One primary action per page or dialog.

Secondary actions must be visually quieter.

Dangerous actions should not compete with normal primary actions.
