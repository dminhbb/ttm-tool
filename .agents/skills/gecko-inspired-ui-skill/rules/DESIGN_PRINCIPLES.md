# Design Principles

## 1. Data first

The interface exists to help users understand state, make decisions, and act.

Decorative elements must never compete with important data.

## 2. Fast scanning

A user should understand the page structure within seconds.

Use:
- strong section hierarchy
- short labels
- aligned values
- consistent spacing
- predictable placement

## 3. Restraint

Use few colors and few font weights.

Prefer hierarchy through:
- size
- spacing
- position
- contrast

## 4. Surface hierarchy

Use 3–4 surface levels at most.

Do not create a new surface color for every card.

## 5. Context matters

Metrics should include context when useful:
- change vs prior period
- target
- status
- threshold
- trend

## 6. Density with clarity

Business software can be dense.

Density is acceptable if:
- grouping is clear
- spacing is consistent
- hierarchy is strong
- interactions are predictable

## 7. Consistency beats novelty

Use existing components even when a custom control might look more unique.

## 8. Design for real data

Test with:
- long names
- large numbers
- empty states
- error states
- loading
- permission limitations
- many rows
