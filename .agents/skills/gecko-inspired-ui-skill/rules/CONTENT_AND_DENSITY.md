# Content and Density

## Labels

Prefer concise labels.

Good:
- Revenue
- Open incidents
- Due date
- Assignee

Avoid:
- Total number of currently open incidents

## KPI values

Use short formatting where useful:
- 1.2K
- 4.8M
- 98.7%

Use full values when exact precision is required.

## Helper text

Use helper text for:
- consequences
- format
- non-obvious constraints

Do not explain obvious controls.

## Empty states

An empty state should explain:
1. what is missing
2. why it matters
3. what action is available

## Dense pages

Use:
- section headers
- tabs
- filter bars
- collapsible advanced settings

Do not solve density by shrinking text below readable sizes.
