# Overlay Components

## Modal

Classes:
- `.ui-modal-backdrop`
- `.ui-modal`
- `.ui-modal__header`
- `.ui-modal__body`
- `.ui-modal__footer`

Use for:
- confirmation
- short create form
- destructive action
- small decision

## Drawer

Classes:
- `.ui-drawer-backdrop`
- `.ui-drawer`
- `.ui-drawer__header`
- `.ui-drawer__body`
- `.ui-drawer__footer`

Use for:
- object details
- edit workflow
- medium-length forms

## Popover

Use for:
- contextual menu
- filter
- date picker
- small inline control

Avoid using a popover for long forms.
