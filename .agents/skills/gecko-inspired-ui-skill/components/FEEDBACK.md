# Feedback Components

## Alert

Classes:
- `.ui-alert`
- `.ui-alert-info`
- `.ui-alert-success`
- `.ui-alert-warning`
- `.ui-alert-danger`

Use alerts for meaningful page-level messages.

## Toast

Use for:
- save confirmation
- non-blocking feedback
- background action result

Do not use toast for:
- critical decisions
- field validation

## Empty state

Classes:
- `.ui-empty`
- `.ui-empty__title`
- `.ui-empty__text`

## Loading

Use skeletons for page content.

Use spinner for short isolated actions.

Avoid full-screen spinner unless the entire application is genuinely unavailable.
