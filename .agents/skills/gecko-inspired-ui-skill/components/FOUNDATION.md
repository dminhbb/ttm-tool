# Foundation Components

## Typography

Classes:
- `.ui-page-title`
- `.ui-section-title`
- `.ui-card-title`
- `.ui-text`
- `.ui-text-sm`
- `.ui-muted`
- `.ui-mono`

## Badge

Use `.ui-badge`.

Variants:
- `.ui-badge-neutral`
- `.ui-badge-success`
- `.ui-badge-warning`
- `.ui-badge-danger`
- `.ui-badge-info`

## Tag

Use for categories and labels rather than workflow state.

Class:
- `.ui-tag`

## Status

Classes:
- `.ui-status`
- `.ui-status-success`
- `.ui-status-warning`
- `.ui-status-danger`
- `.ui-status-info`

Preferred style:
status dot + text.

## Avatar

Class:
- `.ui-avatar`

For grouped avatars:
- `.ui-avatar-group`

## Divider

Class:
- `.ui-divider`

## Skeleton

Class:
- `.ui-skeleton`
