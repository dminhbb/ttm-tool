# Dashboard Components

## Metric Card

Classes:
- `.metric-card`
- `.metric-card__label`
- `.metric-card__value`
- `.metric-card__delta`
- `.metric-card__meta`

Use for:
- one important number
- metric + comparison
- metric + target

## Sparkline Card

Use:
- metric value
- compact trend line
- short comparison

Avoid axes unless necessary.

## Chart Card

Classes:
- `.chart-card`
- `.chart-card__header`
- `.chart-card__title`
- `.chart-card__meta`
- `.chart-card__body`

## Gauge

Use for:
- target completion
- bounded SLA
- threshold state

Avoid gauge for unbounded values.

## Leaderboard

Use for:
- ranking
- team performance
- top categories

## Status Summary

Use for:
- incidents
- risk levels
- workflow status counts

## Dashboard layout

Prefer:
- 4 small KPI cards
- 1–2 primary charts
- 1 detailed table / list
- 1 status or alert panel

Do not fill the page with equal-size cards.
