# Data Table Components

## Structure

Use semantic `<table>` markup.

Classes:
- `.ui-table-wrap`
- `.ui-table`
- `.ui-table-toolbar`
- `.ui-table-actions`
- `.ui-pagination`

## Header

Headers:
- concise
- muted
- semibold
- sticky when helpful

## Rows

Rows should have:
- subtle separators
- hover state
- optional selected state

## Alignment

Text -> left

Status -> left

Dates -> left

Numbers -> right

Currency -> right

Actions -> right

Checkbox -> center

## Density

Default row height:
44–48px.

Compact mode may use 36–40px if requested.

## Actions

Prefer:
- primary row action via clicking name/title
- secondary actions in overflow menu

Avoid many icon buttons in every row.

## Empty state

Use a single full-width row or dedicated panel with:
- description
- relevant action
