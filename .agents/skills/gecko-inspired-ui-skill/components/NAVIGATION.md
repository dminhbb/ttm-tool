# Navigation Components

## App sidebar

Classes:
- `.app-sidebar`
- `.app-sidebar__brand`
- `.app-nav`
- `.app-nav__item`
- `.app-nav__item.is-active`

## Top bar

Classes:
- `.app-topbar`
- `.app-topbar__actions`

## Breadcrumb

Classes:
- `.ui-breadcrumb`
- `.ui-breadcrumb__item`

## Tabs

Classes:
- `.ui-tabs`
- `.ui-tab`
- `.ui-tab.is-active`

Rules:
- use for peer-level views
- do not use for long multi-step workflows
- avoid wrapping tabs across multiple lines
