# Action Components

## Button

Base:
- `.ui-button`

Variants:
- `.ui-button-primary`
- `.ui-button-secondary`
- `.ui-button-ghost`
- `.ui-button-danger`

Sizes:
- `.ui-button-sm`
- `.ui-button-lg`

## Icon button

Class:
- `.ui-icon-button`

Icon-only buttons require accessible names.

## Button group

Class:
- `.ui-button-group`

Use for tightly related actions only.

## Action priority

Every page should usually have:
- 1 primary action
- 0–3 secondary actions
- optional overflow menu

Avoid displaying 5+ equally prominent buttons.
