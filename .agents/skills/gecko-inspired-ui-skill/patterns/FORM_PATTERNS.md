# Form Patterns

## Create form

Use:
- clear page title
- short explanation
- logical sections
- sticky or clearly visible actions for long forms

## Edit form

Avoid mixing read-only and edit modes unpredictably.

Use either:
- dedicated edit mode
or
- clearly scoped inline editing

## Form section

Each section should represent one concept.

Good:
- General information
- Ownership
- Schedule
- Notifications

## Actions

Primary:
Save / Create

Secondary:
Cancel

Danger:
Delete should be separated from normal save actions.

## Long forms

Use full page or drawer.

Do not place 15+ fields in a modal.
