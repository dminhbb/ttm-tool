# Settings and Administration Patterns

## Settings navigation

Use a secondary sidebar or vertical nav when settings has many categories.

Use tabs only for a small number of peer sections.

## Settings page

Preferred structure:
- title
- description
- grouped sections
- save action

## Dangerous settings

Use a separate "Danger zone" section.

Do not visually mix deletion/destructive actions with routine settings.

## Admin tables

Use standard DataTable.

Support:
- search
- filter
- status
- role
- last activity
- row actions
