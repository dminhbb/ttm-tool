# Detail Patterns

## Entity detail page

Header:
- entity name
- status
- key metadata
- actions

Body:
- summary
- key metrics
- related data
- activity/history

## Two-column detail

Left:
main content

Right:
metadata / status / owner / dates

Use only on medium and large screens.

## Detail drawer

Recommended width:
420–560px

Use when users need to inspect an item without losing list context.
