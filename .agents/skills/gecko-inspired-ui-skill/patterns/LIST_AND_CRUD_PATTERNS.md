# List and CRUD Patterns

## Page structure

Page title
Short description
Primary action

Filter/search toolbar

Data table

Pagination

## Toolbar

Left:
- search
- filters

Right:
- export
- settings
- primary action if appropriate

## Row actions

Prefer:
- click item name for details
- overflow menu for secondary actions

## Bulk actions

Show bulk actions only after selection.

## Detail handling

Use drawer when the user should remain in list context.

Use full page when the object has many sub-sections.
