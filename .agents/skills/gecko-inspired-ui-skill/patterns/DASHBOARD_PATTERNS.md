# Dashboard Patterns

## Recommended composition

Top:
page title + time range + primary action

Row 1:
3–4 KPI cards

Row 2:
primary trend chart + comparison chart

Row 3:
table/list + alert/status panel

## Hierarchy

The most important metric or chart should:
- appear higher
- occupy more space
- use stronger contrast

Do not make every widget the same size.

## KPI context

Prefer:
- value
- delta
- baseline
- target

Example:

Revenue
$823.8K
↑ 12.4%
vs previous month

## Monitoring dashboard

Recommended sections:
- health summary
- active risks
- SLA
- incidents
- trend
- recent events

## Executive dashboard

Recommended sections:
- business KPIs
- trend
- target progress
- top movers
- short summary
